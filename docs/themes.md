# Оформление

Оформление сайта — одна тема (`nordic`) с двумя схемами: светлой
(натуральная, отдаётся по умолчанию) и тёмной (переключатель в шапке).

## Из чего состоит оформление

| Часть           | Файл                          | Что там                                                                                          |
| --------------- | ----------------------------- | ------------------------------------------------------------------------------------------------ |
| Оформление      | `src/theme.ts`                | схема по умолчанию, роли шрифтов, цвета обеих схем, адреса субсетов, атрибуты `<html>`           |
| Цвета           | `src/themes/tokens.ts`        | `lightTokens` и `darkTokens` — единственный источник цветов                                      |
| Характер темы   | `src/themes/nordic/theme.css` | сигнатурные правила (радиус); только `color-mix()` от переменных                                 |
| Шрифты          | `src/fonts/`                  | `@font-face` по семейству, список — `src/fonts/manifest.ts`                                      |
| Параметры стиля | `src/styles/tokens.css`       | переменные: типографика, отступы, плотность, карточки, кнопки, слои, движение, производные цвета |
| Правила         | `src/styles/`                 | сброс, разметка, компоненты и блоки страниц (`base`, `layout`, `components-*.css`)               |

## Как это собирается

`scripts/gen-theme-tokens.mjs` генерирует `src/themes/generated/nordic.css`
(`:root` для светлой схемы и `[data-scheme='dark']` для тёмной, источник —
`src/themes/tokens.ts`) — запускается в `dev`/`build`, в git не лежит.
`theme.css` подключает этот файл, поэтому цвета темы приходят последними
и перекрывают дефолты.

Схема переключается атрибутом `data-scheme` на `<html>` (`src/scripts/scheme.ts`):
ранний inline-скрипт в `Base.astro` восстанавливает выбор из localStorage
до первой отрисовки, кнопка в шапке переключает и обновляет
`<meta name="theme-color">`.

`<meta name="theme-color">` выводится из токенов (`accentHex`, `src/themes/brand.ts`),
дублировать hex не нужно.

## Параметры стиля

Параметры (шрифты, плотность, карточки, кнопки, ритм секций, текстура)
лежат в `src/styles/tokens.css` обычными правилами на `:root`.
Смена оформления — правка значений там и/или в `src/themes/tokens.ts`
(цвета). После правки:

```bash
npm run build        # сборка
npm run check:colors # контраст всех наборов
```

## Правила

1. Схема меняет только цвета, не формы и шрифты.
2. В `theme.css` нет литеральных цветов — только `color-mix()` от переменных.
3. Пороги контраста: `ink/bg ≥ 8`, `ink-soft ≥ 4.5`, ссылки, кнопки и
   текст на акценте `≥ 4.6`, контуры `≥ 3` (`npm run check:colors`).
