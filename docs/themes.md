# Оформление

Оформление сайта — одна тема (`nordic`) с двумя схемами: светлой
(натуральная, отдаётся по умолчанию) и тёмной (переключатель в шапке).

## Из чего состоит оформление

| Часть | Файл | Что там |
|---|---|---|
| Цвета | `src/themes/tokens.ts` | base (светлая) и alt (тёмная) — единственный источник цветов |
| Характер темы | `src/themes/nordic/theme.css` | сигнатурные правила (радиус); только `color-mix()` от переменных |
| Реестр | `src/data/themes.ts` | имя, натуральная схема, доступные шрифты |
| Шрифты | `src/themes/entries/nordic.ts` | какие семейства везёт тема (они же попадают в сборку) |
| Параметры стиля | `src/styles/params.css` | запечённые значения: шрифты, плотность, карточки, кнопки, первый экран, текстура |

## Как это собирается

`scripts/gen-theme-tokens.mjs` генерирует `src/themes/generated/nordic.css`
(блоки `[data-skin]` и `[data-scheme='dark']`) — запускается в `dev`/`build`,
в git не лежит. `theme.css` подключает этот файл, поэтому цвета темы
приходят последними и перекрывают дефолты.

Схема переключается атрибутом `data-scheme` на `<html>` (`src/scripts/scheme.ts`):
ранний inline-скрипт в `Base.astro` восстанавливает выбор из localStorage
до первой отрисовки, кнопка в шапке переключает и обновляет
`<meta name="theme-color">`.

`<meta name="theme-color">` выводится из токенов (`schemeBrand`),
дублировать hex не нужно.

## Параметры стиля

Параметры (шрифты, плотность, карточки, кнопки, первый экран, текстура)
запечены в `src/styles/params.css` обычными правилами на `:root`.
Порядок подключения важен: `tokens` → `params` → слои → `@skin`, поэтому
тема может переопределить любой токен у себя.

Смена оформления — правка значений в `params.css` (и/или `tokens.css`);
после правки:

```bash
npm run build        # сборка
npm run check:colors # контраст всех наборов
```

## Правила

1. Схема меняет только цвета, не формы и шрифты.
2. В `theme.css` нет литеральных цветов — только `color-mix()` от переменных.
3. Пороги контраста: `ink/bg ≥ 8`, `ink-soft ≥ 4.5`, ссылки и текст на акценте `≥ 4.6`
   (`npm run check:colors`).
