# Данные сайта

Весь контент лежит в `src/data/` и собирается в страницы на этапе
сборки. Правка данных не требует правки шаблонов: таблицы цен,
карточки услуг и JSON-LD строятся из одних и тех же констант.

## `site.ts` — компания

Телефон, email, Telegram, юридические реквизиты, районы выезда.
Поля, которых ещё нет у клиента, — `null as Pending<T>` («требуется
от клиента»): JSON-LD такие поля не отдаёт, а футер показывает честную
пометку `hasLegal()`.

## `prices.ts` — цены

- `AREA_TIERS` — границы диапазонов площади (каждый тариф даёт ровно
  6 цен: тип `tiers` не соберётся с другим числом);
- `plans` — тарифы по услугам с отметкой `popular`;
- `hourlyRate` — почасовая ставка Смарт Клининга (минимум часов × цена);
- `MIN_ORDER`, `areaUpTo/areaOver` — подписи и минимальный заказ.

Таблица цен (`PriceTableGrid`), карточки услуг и калькулятор читают
одни и те же числа — расхождение между страницами невозможно.

## `legal/` — юридические тексты

Документы разложены по локалям (`privacy.sr/en/ru.ts`, `terms.*`).
Порядок разделов во всех версиях одинаков — при сборке проверяется,
что их число совпадает, иначе сборка падает. Тексты — шаблоны:
их должен утвердить юрист.

## Прочий контент

| Что                     | Файл                   |
| ----------------------- | ---------------------- |
| Услуги и их состав      | `src/data/services/`   |
| Чек-листы работ         | `src/data/checklists/` |
| Дополнительные услуги   | `src/data/extras.ts`   |
| Шаги работы и УТП       | `src/data/steps.ts`    |
| FAQ                     | `src/data/faq.ts`      |
| Отзывы (сейчас образец) | `src/data/reviews.ts`  |
| Состав страниц          | `src/data/pages.ts`    |
| Темы оформления         | `src/data/themes.ts`   |

Локализованные массивы (пункты чек-листов) проверяются на паритет
длин при сборке — рассинхрон переводов уронит `npm run build`.
